How to play
  1. Everyone opens this page on their own phone or laptop.
  2. Players pick a team (A, B, C or D). The host picks "I'm the Host".
  3. The host reads a question aloud, then taps Start Round.
  4. Players tap BUZZ (or press Space). First to buzz stops the clock for everyone.
  5. The host taps Correct (+10) or Wrong (−5).
