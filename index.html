How to play
  1. Everyone opens this page on their own phone or laptop.
  2. Players pick a team. The host taps "I'm the host".
  3. The host reads a question aloud, then taps Start round.
  4. Players tap BUZZ (or press Space). The first team to buzz stops the clock. Other teams have 3 seconds to join the line.
  5. Correct gives +10 points. Wrong costs nothing and the turn goes to the next team in buzz order.

Can't connect

The Firebase library could not load. Check your internet connection and reload the page.

Connect your Firebase database

  1. Open console.firebase.google.com → Add project.
  2. Build → Realtime Database → Create database (test mode).
  3. On the Rules tab paste {"rules":{".read":true,".write":true}} and Publish.
  4. Project settings → Your apps → Web → copy the config.
  5. Paste it into FIREBASE_CONFIG in this file and change HOST_CODE.
  6. Save and reload.
